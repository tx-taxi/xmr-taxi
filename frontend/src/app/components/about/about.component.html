About xmr.tx.taxi

xmr.tx.taxi is a fork of mempool.space retargeted to Monero. It surfaces what the chain alone proves - height, hashrate, mempool, fee tiers, ring information, and RingCT type - and stops there. Amounts and recipients are hidden by Monero's RingCT and stay hidden in the default render.

Privacy by default

Transaction-detail pages blur sensitive fields by design. Participant-side disclosure is limited to flows that match Monero's privacy model:

  • Recipient checks — require the recipient's own wallet/view key tooling. Private keys should stay local.
  • tx_proof verification — a tx_proof signature plus recipient address can be checked by the backend when the operator configures monero-wallet-rpc. No private keys are sent.
  • tx_secret_key checks - belong in local wallet tooling; xmr.tx.taxi does not ask users to send that key to the server.
Daemon

This deployment uses a configured pool of public restricted-RPC Monero nodes with ordered fallbacks. Operators can point a self-hosted instance at any compatible monerod JSON-RPC endpoint.
