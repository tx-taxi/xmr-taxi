# Shared tx.taxi documentation intro

The docs mount `TxTaxiDocsIntroComponent`, a standalone Angular component copied verbatim from explorer-kit/templates/tx-taxi-docs-intro. Its chainName/chainHost inputs provide native context. CTA destinations are https://tx.taxi/ and the native root `/`.

The background asset is an actual tx.taxi hub capture from 2026-09-26 at 1600px viewport width, encoded as `hub-chains-ece0809c4b.webp`. Angle and transparency are CSS; imagery does not replace text. Colors follow existing theme variables including Mempool Original. Decorative imagery is hidden from assistive technology.

Integration uses a sticky docs sidebar contained below the taller intro and bounded code examples. Final screenshots, production build commands, local URLs, browser interaction results and cross-chain evidence are in `/home/lukee/dev/tx-taxi-docs-review/README.md`.

This candidate has not been deployed. Provider, router, search and native block-strip code is outside this change.
