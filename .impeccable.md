## Design Context

Users: blockchain explorer visitors learning to interpret their chain and developers reading its real public API. The shared CTA explains the router to both.

Creator-directed visual context: preserve the comprehensive Mempool docs layout, current fonts, chain colors and Mempool Original option. Precise, familiar, restrained. No new design system. At the top, use one unified tx.taxi explainer with an actual hub screenshot tilted and slightly transparent behind readable copy. Chain content must reflect real semantics and available endpoints.

Principles: reuse native docs layout; keep explanatory text legible over decorative imagery; adapt themes through existing tokens; preserve mobile navigation and readable code; never invent API support.
